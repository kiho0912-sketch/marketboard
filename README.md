# 마켓보드 v1.1 — 갤럭시·PC용 환율·국내주식 통합 화면

## v1.1 수정사항
- TradingView의 외부 임베드 제한으로 코스피·코스닥·국내 종목 차트가 깨지는 문제 수정: **국내시장 부분을 자체 SVG 차트로 교체**.
- 코스피/코스닥, 관심주식 10개를 가격/전일대비/변동률/일별 그래프 카드로 표시하고, 상세 화면에 1주·1개월·3개월·1년·3년·5년 버튼 추가.
- `api/market.js` Vercel Function 추가: 브라우저 CORS 제한을 피하기 위해 서버에서 공개 시세를 읽어 필요한 데이터만 반환. 캐시를 통해 반복 호출 감소.
- 갤럭시에서 홈 화면에 추가하기 위한 PWA 설정과 아이콘 추가.
- 페이지가 열려 있는 동안 국내 시세 3분 주기 재조회, 화면으로 돌아올 때 시세 다시 조회 (데이터 제공처 정책에 따라 지연될 수 있음).
- 환율 카드·계산기는 이전 버전의 TradingView 환율 그래프 및 일일 참고환율 유지.

## 주요 주의 사항
**v1.1은 `index.html`을 휴대폰 파일 앱에서 직접 열어도 국내 주식·지수 시세가 작동하지 않습니다.** 국내 시세를 가져오는 `/api/market` 서버 함수가 있어야 하므로 프로젝트 폴더 **전체**를 Vercel에 배포해야 합니다. HTML만 업로드하면 `/api/market`이 없어 조회에 실패합니다.

해당 소스는 개인 학습·시범 용도입니다. **네이버 금융 공개 인터페이스 및 Yahoo Finance 비공식 시세 경로는 제공업체에서 공식적으로 안정성과 재배포 권한을 보장하는 데이터 API가 아닙니다.** API 구조변경, 정책, 호출 제한, 접속환경에 따라 표시되지 않을 수 있습니다. 유료 서비스·공개 배포에는 정식 데이터 이용 허가 또는 증권사/거래소 정식 API가 권장됩니다. 특정 응답 시간이나 실시간 시세를 보장하지 않으며, 실제 거래에는 증권사/거래소 공식 값을 확인하세요.

## Vercel 배포하기 (권장)
1. ZIP 압축을 풉니다. `marketboard_site/` 안에 `index.html`, `api/market.js`, `package.json`, `vercel.json`, 아이콘 파일 등이 함께 있어야 합니다.
2. PC에서 https://vercel.com/ 가입 또는 로그인합니다.
3. 가장 쉬운 방법: https://vercel.com/docs/cli 의 Vercel CLI를 설치하고, 명령 프롬프트에서 `marketboard_site` 폴더로 이동하여 `vercel --prod`를 실행합니다. (초기에는 `npm install -g vercel` 설치)
4. 또는 이 폴더 전체를 GitHub 저장소에 올리고 Vercel → **Add New → Project → Import Git Repository**에서 저장소를 선택한 후 Deploy합니다. 프레임워크는 **Other**로 설정하고 Root Directory는 `index.html`이 있는 폴더입니다.
5. 배포 후 주소가 `https://프로젝트명.vercel.app` 형식으로 만들어집니다. `https://프로젝트명.vercel.app/api/market?type=index&code=KOSPI&range=3mo`에 접속해 `"ok":true`가 나오는지 확인합니다. JSON 에러가 뜨면 시세 제공처 측 정책/접속 제한일 수 있습니다.
6. URL에 접속하여 코스피/코스닥/삼성전자 카드가 나오는지 확인하세요.

## 갤럭시에서 홈 화면에 설치하기
- 삼성 인터넷 또는 Chrome에서 배포된 **https://** 사이트 주소를 엽니다.
- 삼성 인터넷: 하단 메뉴 → 현재 페이지 추가 → 홈 화면, Chrome: 오른쪽 위 ⋮ → 홈 화면에 추가 또는 앱 설치.
- 홈 화면에 **마켓보드** 아이콘이 생성됩니다. 누르면 전체 화면 앱처럼 실행할 수 있습니다.
- 상시 사용하려면 브라우저/앱을 켜 두세요. 화면이 꺼진 동안 시세 갱신이 계속된다고 보장하지 않습니다. 다시 들어오면 시세를 갱신합니다.

## 환율과 주식의 데이터 종류가 다릅니다
- USD/JPY/CNY 카드의 큰 숫자·환산 계산기는 `https://open.er-api.com/v6/latest/USD`의 일일 참고환율입니다. 은행 고시환율이 아닙니다.
- 카드 안의 환율 그래프는 TradingView 시장호가 위젯입니다. 은행 기준환율과 다른 숫자가 보일 수 있습니다.
- 코스피/코스닥/관심주식은 공개 시세의 최근 값(지연 가능)을 카드에 표시합니다. 차트는 **거래일별 종가**이며 실시간 분봉 차트가 아닙니다.
- 종목 데이터의 원천은 네이버 금융의 비공식 공개 엔드포인트이며, 실패 시 Yahoo Finance 비공식 JSON 경로로 보조 조회합니다. 두 출처 값은 달라질 수 있습니다.
- 관심종목은 각 기기의 브라우저 localStorage에 저장됩니다. PC와 휴대폰 사이에 **자동 동기화되지 않습니다.**
- 수동 갱신 버튼과 테마 변경 버튼이 있습니다.

## 장애 대응
- **국내 주식에 "시세를 불러오지 못했습니다"가 나옴:** `index.html`을 직접 연 상태이거나, `/api/market` Vercel 함수가 설치되지 않았거나, 시세 제공처에서 접속을 막고 있을 수 있습니다. ZIP 전체 재배포하고 위의 API URL을 테스트하세요.
- **`/api/market` 404:** `api/market.js`가 루트 폴더 아래에 있는지 확인하세요. 파일 하나만 배포하면 안 됩니다.
- **`/api/market` 502:** 시세 제공처가 요청을 거부/제한했을 수 있습니다. 화면에서 해당 종목의 네이버 금융 링크로 확인하고 추후 공식 API로 교체하세요.
- **환율 그래프 오류:** 외부 TradingView 위젯이 차단되었거나 시세 접근 정책이 달라졌을 수 있습니다.
- **원화 환산 오류:** 환산용 API가 일시 접속 실패했을 수 있습니다.
